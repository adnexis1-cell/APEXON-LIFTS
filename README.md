## 📦 How to Upload to GitHub & Deploy Live (Free)

### Option 1: Using GitHub Desktop or Git CLI
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Apexon Lifts website"
   ```
2. Create a new repository on GitHub (e.g. `apexon-lifts`).
3. Push to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/apexon-lifts.git
   git branch -M main
   git push -u origin main
   ```
4. **Enable GitHub Pages:**
   - Go to your repo **Settings** > **Pages**.
   - Under *Build and deployment*, set Source to **Deploy from a branch** (select `main` / `root`).
   - Click **Save**. Your site will be live at `https://<your-username>.github.io/apexon-lifts/` within 60 seconds!
